Who operates this

This website and the Pinterest application described below are operated by Omar Alsamman, doing business as Ionix ("Ionix", "we"). Contact: ionixselonita@gmail.com.

What the application does

Ionix operates a Pinterest developer application for the account owner's own use. After the owner authorizes it through Pinterest, the application uses the Pinterest API to read the owner's own boards and Pins, and to create Pins and boards on the owner's own Pinterest account, for example to publish product Pins for the owner's print-on-demand store.

What data it handles

The application only handles Pinterest account data that the Pinterest API returns for the authorized account: that account's profile information, boards, and Pins. It does not access any other person's Pinterest account. This page is a static document: it sets no cookies and includes no analytics or tracking scripts.

How the data is used

Data returned by the Pinterest API is used only to view, organize, and publish the owner's own Pins and boards, as described above.

Sharing

We do not sell, rent, or share Pinterest account data with third parties.

Revoking access

The account owner can revoke the application's access at any time in their Pinterest account settings, under the connected apps / privacy settings. Revoking access immediately stops the application from accessing the account through the Pinterest API.

If this policy changes, the updated version will be posted at this same address with a new date.
